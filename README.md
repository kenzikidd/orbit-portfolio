# orbit. — цифровая орбита

Личное портфолио независимого веб-разработчика. Русский и английский интерфейс, космическая сцена, анимации прокрутки и живые превью трёх демонстрационных сайтов: КОНТУР 1.1, Тёплый угол и FORMA.

Контакт: kenzikidd@proton.me.

## Публикация

GitHub Actions публикует сайт в GitHub Pages после изменений в main. Источник Pages в настройках репозитория — GitHub Actions.

`index.html`, `styles.css`, `app.js` и `data.js` — актуальные исходники портфолио. Контакты, проекты и все переводы находятся в `data.js`.

`orbit-site.zip` — пакет статических ресурсов и самостоятельных копий демонстрационных проектов. Workflow распаковывает его, затем накладывает актуальные четыре исходных файла из корня. Локальные серверы, промежуточные материалы и служебные отчёты не публикуются.

Для изменения текстов и ссылок достаточно отредактировать data.js и сохранить в main. Для добавления файлов изображений или обновления вложенного проекта обновите соответствующие файлы внутри orbit-site.zip с сохранением относительных путей. Архив раскрывается непосредственно в корень сайта.

## Локальный просмотр

Распакуйте orbit-site.zip в папку и замените четыре исходных файла актуальными из корня репозитория. Запустите любой статический HTTP-сервер в этой папке. Сборка приложения и установка зависимостей не требуются.

Все бизнесы в проектах вымышленные. Демонстрационные формы не отправляют заявки и не принимают оплату. КОНТУР использует иллюстративные фотографии Unsplash; кофейня и FORMA — локальные фотографии Unsplash. Шрифт Manrope загружается из Google Fonts с системным резервным шрифтом.
